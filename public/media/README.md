Drop a video file here to have it play automatically — no code changes
needed. Expected filenames (referenced in the code):

glass-showcase.mp4   — used as the Gallery page's hero banner
glass-showcase.jpg   — poster image shown while the video loads (optional)

Until a file exists at these paths, an animated 3D glass-pane visual is
shown instead — the site never shows a broken video icon.

Where to get real footage (don't hotlink random internet videos — check
the license first):
- Your own footage of actual glasswork/construction in progress is best —
  it's real proof of the work, not stock content.
- Pexels Videos (pexels.com/videos) and Coverr (coverr.co) offer video
  under free commercial-use licenses — search "glass building" or
  "architecture glass facade".

Keep video files reasonably small (a 10–20 second loop, compressed,
under ~10MB) so the page still loads fast.
