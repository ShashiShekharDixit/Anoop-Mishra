Per-project videos go here. Expected filenames (already wired into the
code, referenced from each project's `video` field in src/data.ts):

central-academy.mp4
park-inn-radisson.mp4

Drop a file with the matching name here and a "Video" tab automatically
appears next to "Photos" in that project's gallery modal — no code
changes needed. Projects without a `video` field in data.ts (the smaller
ones) won't show a video tab at all, which is intentional — don't add
one just to fill space.

Same licensing note as public/media/README.md: use your own project
footage, or properly licensed free-commercial-use stock video if you
don't have your own yet.
